# Project Safety Rules

- Work only inside the current project directory.
- Never modify, move, or delete files outside this project.
- Never run recursive deletion or cleanup commands.
- Never delete databases, backups, environment files, or project configuration.
- Ask for explicit approval before destructive operations.
- Do not run commands that modify files outside the project.
- Inspect existing code before replacing or rebuilding it.
- Preserve the existing frontend and database.
